# Orders Feature - Quick Reference Guide

## Usage Examples

### 1. Display Order List

```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:cangkang_sawit_app/features/orders/presentation/providers/order_notifier.dart';

class MyOrdersPage extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // Watch order state
    final orderState = ref.watch(orderNotifierProvider);

    // Load orders on init
    ref.listen(orderNotifierProvider, (previous, next) {
      if (previous == null) {
        ref.read(orderNotifierProvider.notifier).loadOrders();
      }
    });

    return Scaffold(
      body: orderState.isLoading
          ? Center(child: CircularProgressIndicator())
          : ListView.builder(
              itemCount: orderState.orders.length,
              itemBuilder: (context, index) {
                final order = orderState.orders[index];
                return ListTile(
                  title: Text(order.orderNumber),
                  subtitle: Text('Status: ${order.status}'),
                  trailing: Text('\$${order.totalAmount}'),
                );
              },
            ),
    );
  }
}
```

### 2. Create New Order

```dart
import 'package:cangkang_sawit_app/features/orders/domain/entities/order.dart';
import 'package:cangkang_sawit_app/features/orders/presentation/providers/order_notifier.dart';

// Inside a StatefulWidget or function
Future<void> createOrder(WidgetRef ref) async {
  final order = Order(
    id: '', // Will be generated by backend
    orderNumber: '', // Will be generated by backend
    customerId: 'customer-123',
    orderDate: DateTime.now(),
    status: 'pending',
    totalQuantity: 100,
    totalAmount: 1000000,
    createdAt: DateTime.now(),
    pickupAddress: 'Jl. Sudirman No. 123',
    deliveryAddress: 'Jl. Thamrin No. 456',
    customerNotes: 'Please deliver before 5 PM',
  );

  final success = await ref.read(orderNotifierProvider.notifier).createOrder(order);

  if (success) {
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Order created successfully!')),
    );
  } else {
    final errorMessage = ref.read(orderNotifierProvider).errorMessage;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Error: $errorMessage')),
    );
  }
}
```

Future<void> loadOrderDetails(WidgetRef ref, String orderId) async {

### 8. Handle Loading and Error States

```dart
class OrderListWidget extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final orderState = ref.watch(orderNotifierProvider);

    // Show loading
    if (orderState.isLoading) {
      return Center(child: CircularProgressIndicator());
    }

    // Show error
    if (orderState.errorMessage != null) {
      return Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Icon(Icons.error, color: Colors.red, size: 48),
            SizedBox(height: 16),
            Text(orderState.errorMessage!),
            ElevatedButton(
              onPressed: () {
                ref.read(orderNotifierProvider.notifier).clearError();
                ref.read(orderNotifierProvider.notifier).loadOrders();
              },
              child: Text('Retry'),
            ),
          ],
        ),
      );
    }

    // Show data
    return ListView.builder(
      itemCount: orderState.orders.length,
      itemBuilder: (context, index) {
        return OrderCard(order: orderState.orders[index]);
      },
    );
  }
}
```

### 10. Testing Use Cases

```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:mockito/mockito.dart';
import 'package:dartz/dartz.dart';

void main() {
  late CreateOrder useCase;
  late MockOrderRepository mockRepository;

  setUp(() {
    mockRepository = MockOrderRepository();
    useCase = CreateOrder(mockRepository);
  });

  test('should create order successfully', () async {
    // Arrange
    final order = Order(...);
    when(mockRepository.createOrder(any))
        .thenAnswer((_) async => Right(order));

    // Act
    final result = await useCase(order);

    // Assert
    expect(result, Right(order));
    verify(mockRepository.createOrder(order));
  });
}
```

## Available Status Values

- `pending` - Order created, awaiting admin confirmation
- `confirmed` - Admin confirmed the order
- `shipped` - Order is being delivered
- `completed` - Order successfully completed
- `cancelled` - Order was cancelled

## Common Patterns

### Pull to Refresh

```dart
RefreshIndicator(
  onRefresh: () async {
    await ref.read(orderNotifierProvider.notifier).loadOrders();
  },
  child: OrderList(),
)
```

### Search/Filter Dropdown

```dart
DropdownButton<String>(
  value: _selectedStatus,
  items: ['All', 'pending', 'confirmed', 'shipped', 'completed']
      .map((status) => DropdownMenuItem(value: status, child: Text(status)))
      .toList(),
  onChanged: (status) {
    setState(() => _selectedStatus = status);
    ref.read(orderNotifierProvider.notifier).loadOrders(
      status: status == 'All' ? null : status,
    );
  },
)
```

onTap: () {

## Error Handling

All operations return boolean success indicators. Check errors like this:

```dart
final success = await ref.read(orderNotifierProvider.notifier).createOrder(order);

if (!success) {
  final error = ref.read(orderNotifierProvider).errorMessage;
  // Handle error
  print('Error: $error');
}
```

## Performance Tips

1. **Filter on Backend**: Always use status/customerId filters when possible
2. **Pagination**: For large lists, implement pagination (future enhancement)
3. **Caching**: Order state is cached in memory while app is running
4. **Refresh**: Use pull-to-refresh pattern for manual updates
5. **Real-time**: Consider Supabase realtime subscriptions for live updates
